# Jishaku package

Owner debug cog. It is not a sandbox. Eval runs as the bot. Load it only
where owners are people you trust.

| Name | Purpose |
| --- | --- |
| `Jishaku` | Eval, shell, inspect, files, git, pip, network, owner controls. |
| `jsk` | This process, and with Redis telemetry the whole bot: guilds, users, channels, roles, shard readiness, fleet RSS. |
| Non-owners | Dropped silently. |
| `owner_ids` | Who can run it. A hidden command name is not access control. |
